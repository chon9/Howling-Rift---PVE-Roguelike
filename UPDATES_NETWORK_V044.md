# Automatic updates and co-op responsiveness — v0.4.4

Windows release builds check the repository's latest stable GitHub release at startup. The main menu displays installed and latest versions, download status, and a Restart to update button once a verified package is staged. The bottom-right version badge highlights available updates. Downloads happen in a hidden background helper and never interrupt a match. Automatic background downloads default on and can be disabled with the menu checkbox. Offline checks fail gracefully and leave the game playable. Godot editor/source builds support checking versions but do not replace the editor or source files.

The updater accepts only the exact versioned ZIP and SHA-256 asset URLs in this repository. It verifies the full archive before extraction, rejects traversal, foreign roots, duplicate entries, symlinks, unexpected files and oversized extraction, then records hashes of all staged files. Installation rechecks those hashes, waits for the game process to exit, backs up the old game files, installs and relaunches. Copy failures restore backed-up files. The updater does not modify progression saves or unrelated installation files. Updates are cached under user://updates; failures record a readable state JSON there. Read-only installation folders require a manual extracted release in a writable location. This first updater build must be installed manually from GitHub; versions before v0.4.4 cannot discover updates themselves.

Co-op world snapshots now run at 30 Hz instead of 20 Hz and use independent unreliable packets, removing old-state retransmission queues. Compressed snapshots are split into 1,000-byte chunks below the transport MTU. Receivers assemble chunks in any order, discard stale sequences, cap incomplete assemblies and accept subsequent complete snapshots even if an older chunk is lost. Commands, purchases, lobby state and match results remain reliable. Full snapshots recover state without delta dependencies.

Guest presentation estimates velocity from authoritative positions, extrapolates for at most 80 ms, and reconciles movement faster, especially for the local hero. Teleports snap and stun/death disables extrapolation. Damage, cooldowns, movement orders and all combat remain host authoritative. Motion history resets on leave/new match. Steam protocol is 3; every co-op player must use v0.4.4. Real two-PC internet latency and Steam relay performance still depend on the network and require testing with friends; local validation does not measure them.

Also includes the unreleased v0.4.3 Vesper visibility fix: bright silver basic-attack arrows and gold Condemn arrows with compact high-contrast cores and trails.

Validation: 27 deterministic updater/network checks, 16 isolated real PowerShell updater safety/install checks, 12 Vesper checks, 7,267 equipment checks and 1,296 animation checks passed. Host plus two LAN clients passed with zero failures and no MTU warnings. The real GitHub v0.4.2 ZIP/checksum download verified and staged successfully. Main-menu layout was checked natively at 1280x720.

The actual exported v0.4.4 Steam smoke test passed with zero failures, including live GitHub version checking and the packaged updater helper.
