# Generated environment and UI artwork

All assets were created with the built-in image_gen tool and saved in this workspace. Raster artwork is rendered by Godot; unit markers, cooldowns, health, menus, and input controls are live game elements.

## assets/environment/rift-chasm.png

Production fantasy game environment background texture: vertical top-down view into a deep icy ravine, dark blue fractured rock ridges, jagged glacial shelves, frosted crags, scattered snow patches, shadowy abyss and thin wisps of mist. A quiet snowy canyon floor and cliff texture that repeats seamlessly on all edges. Wide landscape 3:2 canvas. Premium detailed painterly 3D materials matching an ancient frozen slate bridge MOBA battlefield. No bridge, no road, no structures, no characters, no UI, no text, no perspective horizon. Mostly dark navy and desaturated cold gray, small subtle teal frost highlights. Physical rock detail at medium scale, no huge dominant object. Must remain crisp when displayed at 800px wide.

Structure atlas crops use measured row dividers (0 / 576 / 952 / 1536) and per-column transparent padding, because generated sprites occupy different heights. The bridge repeats with alternating mirrored tiles to meet identical boundary pixels. UI chrome uses nine regions with separately scaled screen-space corners. No source pixels were hand-painted or replaced with vectors.
