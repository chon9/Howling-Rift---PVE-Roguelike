# Animated minions v2

Generated using OpenAI's built-in image generation tool. Transparent 4-column × 5-row atlas with melee, caster, siege, super and summoned bear rows. Four walking frames per unit, idle pose and attack recoil handled in-game. Blue painted cloth is recolored red by team-cloth.gdshader, preserving metal/fur shading. Original generated image remains in Codex generated_images; project asset: minion-roster-v2.png.
