# Ignite status atlas

Generated with the built-in OpenAI image-generation tool. Transparent four-frame looping fire surrounds an open torso area. Original output preserved in the Codex generated_images folder; project copy: ignite-status-v1.png.

## Prompt

Create a transparent raster sprite sheet for a persistent IGNITE burning status effect in an original serious PC MOBA game. Wide canvas, exactly FOUR equal columns and ONE row, four animation frames left to right. No characters, no text, no labels, no grid, no background. Each frame has the same upright silhouette: licking orange-red flames rise on both sides of an invisible humanoid torso with a generous empty transparent central corridor so the game hero stays readable, smaller fire tongues around the feet and sparse upward embers. Narrow tall footprint, base at bottom, top tongues taper. Restrained hot amber tips, deep red base, translucent textured painted flame edges. Frames change naturally as a looping flame animation, stable scale and baseline. Serious high-fantasy MOBA combat VFX, no explosion, no ring-shaped blast, no cartoon sticker, no smoke covering the center, no exaggerated bloom. Each effect fully inside its cell with generous transparent padding. True alpha background.
